Nord Stage 4

Choisis la banque (couleurs par paires de même LSB). Bloc foncé = page · colonnes = programmes.

Tape comme ça te vient : 11, 1.1, 205 pour le NS2 ; a28, a.2.8, C:3:5 pour le NS4 (sans lettre, la banque actuelle est gardée). Côté MIDI du NS4 : juste le PC, ou LSB:PC (ex. 1:18). Program change de 0 à 127 ; si ton logiciel compte de 1 à 128, ajoute 1. Le patch choisi est surligné dans le tableau. Clique une pastille du tableau pour remplir la case du dessus. Vide un champ pour enlever le surlignage. Le dernier patch choisi reste en mémoire dans ce navigateur.
